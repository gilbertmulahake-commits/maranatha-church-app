# Unit 13.1: Local Church Dashboard

## Goal
Build a dedicated dashboard for `LOCAL_PASTOR` and `CHURCH_TREASURER` roles. It must display their specific church's financial health (Strict Bucket Isolation) and their complete payment history.

## Design
- **Layout:** Uses the existing `AppShell`.
- **KPI Cards:** 
  1. Total Paid (Lifetime).
  2. Annual Status (Paid/Outstanding).
  3. Monthly Status (Paid/Outstanding).
  4. Overall Compliance (Percentage).
- **Payment History:** A table showing all payments made by this specific church.
- **Role Isolation:** This page must strictly fetch data only for the `church_id` linked to the logged-in user.

## Implementation
### 1. Server Action (`lib/actions/local-actions.ts`)
- `getLocalChurchStats()`: Verifies the user has a `church_id`. Fetches the church, calculates expected amounts via `getExpectedUpToDate`, and returns the exact Annual/Monthly breakdowns and payment history.

### 2. UI Components
- Update `app/dashboard/local/page.tsx` (Suspense + connection).
- Create `components/local/local-kpi-cards.tsx`.
- Create `components/local/local-payment-history.tsx`.

## Verification Checklist
- [ ] Local Pastors only see their own church's data.
- [ ] KPI cards correctly show Annual vs Monthly arrears.
- [ ] Payment history table lists only payments made by this church.
- [ ] No TypeScript errors.
