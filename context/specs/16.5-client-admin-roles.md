# Unit 16.5: Client Admin Roles (Finance & Operations)

## Goal
Introduce two new National-level administrative roles: `FINANCE_ADMIN` and `OPERATIONS_ADMIN`. Enforce strict Separation of Duties so that Finance manages money (payments, KCB, arrears) and Operations manages the registry (churches, regions, users). Both roles will have National visibility but restricted functional access. The `SYSTEM_ADMIN` (Super Admin) retains ultimate control.

## Design
- **RBAC Matrix:** 
  - `OPERATIONS_ADMIN`: Can manage Regions, Churches, and Users. Read-only for Payments and no access to Mock KCB.
  - `FINANCE_ADMIN`: Can manage Payments, Reconciliation, and Mock KCB. Read-only for Regions/Churches and no access to Users.
- **Data Scope:** Both roles are National level (all 60 regions visible).
- **UI (Sidebar):** Conditionally hide the "Users" tab from `FINANCE_ADMIN` and hide the "Mock KCB" tab from `OPERATIONS_ADMIN`. 
- **Security:** Protect `SYSTEM_ADMIN` accounts from being modified by anyone except another `SYSTEM_ADMIN`. Protect `ADMIN` accounts from being modified by lower roles.
- **SMS Identity:** Both roles use the `'NATIONAL'` sender role for SMS reminders.

## Implementation

### Dependencies
- No new packages required.

### Database & Schema
- Update `prisma/schema.prisma`: Add `FINANCE_ADMIN` and `OPERATIONS_ADMIN` to the `Role` enum.
- Create a new migration: `npx prisma7 migrate dev --name add_finance_operations_admin_roles`.

### RBAC Helpers (`lib/auth/roles.ts`)
- Add `FINANCE_ADMIN` and `OPERATIONS_ADMIN` to `isNationalLevel()` so they pass the dashboard layout guards.
- Add `isFinanceAdmin(role)` and `isOperationsAdmin(role)` helpers.

### Protected Accounts (`lib/auth/protected-users.ts`)
- Expand the protection logic: Ensure that `FINANCE_ADMIN` and `OPERATIONS_ADMIN` cannot deactivate or change the role of any `SYSTEM_ADMIN` or other `ADMIN` accounts.

### Server Actions Guard Clauses
- `lib/actions/user-actions.ts`: Restrict `inviteUser`, `toggleUserStatus`, `forcePasswordReset`, and `updateUserRole` to `SYSTEM_ADMIN` and `OPERATIONS_ADMIN` only.
- `lib/actions/church-actions.ts` & `region-actions.ts`: Restrict mutations to `SYSTEM_ADMIN`, `OPERATIONS_ADMIN`, and `NATIONAL_TREASURER`.
- `lib/actions/payment-actions.ts` (and any KCB related actions): Restrict mutations to `SYSTEM_ADMIN`, `FINANCE_ADMIN`, and `NATIONAL_TREASURER`.

### Sidebar Navigation (`components/layout/app-sidebar.tsx`)
- Update the `navMain` array for `isNationalLevel(role)`:
  - Add a conditional check: If the user is a `FINANCE_ADMIN`, filter out the `{ title: 'Users', url: '/dashboard/users', ... }` item.
  - Add a conditional check: If the user is an `OPERATIONS_ADMIN`, filter out the `{ title: 'Mock KCB', url: '/dashboard/mock-kcb', ... }` item.

### Files to create / modify
