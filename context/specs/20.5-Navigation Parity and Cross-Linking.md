# Unit 20.5: Navigation Parity & Cross-Linking

## Goal

Unify navigation and cross-linking across Regions and Churches so every entity is reachable via a clickable name from every list view, every preview dialog offers a "Go to [X] Page" CTA, and the browser back button returns users to the page they navigated from rather than a hardcoded fallback. Verifiable by: church names linked in both the National and Regional tables, "Go to Church Page" CTA present in `<ViewChurchDialog>`, and region/church page back buttons honouring browser history.

## Design

### Parity principle

Every list view of an entity type must expose the same navigation affordances the National Churches table already has:

| Entity | National | Regional | Regions |
|---|---|---|---|
| Name is a `<Link>` to its detail page | ✅ (already) | ❌ (missing) | ✅ (already) |
| Action menu has "View Details" | ❌ (missing) | ✅ (already) | ✅ (already) |
| Preview dialog has "Go to [X] Page" CTA | ❌ (missing) | ❌ (missing) | ✅ (already) |
| Action menu has "Edit" | ✅ (already) | ✅ (already) | ✅ (already) |

The gaps are exactly: Regional church names, National church-table View action, `ViewChurchDialog` CTA. Nothing else.

### Back navigation

The `RegionBreakdownDialog` on `/dashboard` already links correctly to `/dashboard/regions/[slug]`, but the region page's back button hardcodes `/dashboard/regions`. That means a user who opened the region page **from the leaderboard** cannot return to `/dashboard` with one click. The back button must honour browser history.

**Pattern:** `router.back()` when browser history exists (`window.history.length > 1`), otherwise fall back to the entity's list page (`/dashboard/regions` or `/dashboard/churches`). Do not add a query parameter (`?from=dashboard`) — that leaks routing state into URLs and breaks when the user shares the link. Use a single shared `EntityBackButton` component to avoid duplicating the `router.back()` logic in two server components.

### Design tokens

- **"Go to [X] Page" CTA:** `<Button className="h-9 bg-primary hover:bg-primary/90">` with `<ExternalLink className="mr-2 h-4 w-4" />`. Matches the existing `RegionBreakdownDialog` footer precedent exactly.
- **Back button:** `<Button variant="ghost" size="icon" className="h-8 w-8">` with `<ArrowLeft className="h-4 w-4" />`. Icon-only to match the current visual; add `aria-label="Go back"` for a11y.
- **Dialog footer:** `<DialogFooter className="pt-4 gap-2 flex-col-reverse sm:flex-row">`. Close on the left (`variant="outline"`), primary CTA on the right.
- **Church name link:** `font-medium text-foreground text-paragraph-small hover:underline` (matches the existing National church-table link styling).

### 1. `components/shared/entity-back-button.tsx` — new file

Create `components/shared/entity-back-button.tsx`:

```tsx
// components/shared/entity-back-button.tsx

'use client'

import { useRouter } from 'next/navigation'
import { Button } from '@/components/ui/button'
import { ArrowLeft } from 'lucide-react'

interface EntityBackButtonProps {
  /** Where to go if there is no browser history (fresh tab / direct visit). */
  fallbackHref: string
}

export function EntityBackButton({ fallbackHref }: EntityBackButtonProps) {
  const router = useRouter()
  return (
    <Button
      variant="ghost"
      size="icon"
      className="h-8 w-8"
      aria-label="Go back"
      onClick={() => {
        if (typeof window !== 'undefined' && window.history.length > 1) {
          router.back()
        } else {
          router.push(fallbackHref)
        }
      }}
    >
      <ArrowLeft className="h-4 w-4" />
    </Button>
  )
}
```
