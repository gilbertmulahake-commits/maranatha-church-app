# Unit 11.1: Reporting UI (Arrears & Cashbook)

## Goal
Build the Reporting dashboard where users can generate structured views of arrears and daily collections. These views are read-only and highly filterable, serving as the foundation for the CSV export engine.

## Design
- **Layout:** Uses the existing `AppShell`. A new page at `/dashboard/reports`.
- **Sub-tabs:** The page will have two internal tabs at the top: **Arrears Report** and **Daily Cashbook**.
- **Arrears Report Tab:**
  - A table of *all* churches with an outstanding balance (Strict Bucket Isolation applied).
  - Columns: Church Code, Church Name, Region, Annual Out, Monthly Out, Total Out.
  - Grouping/Summary row for the total arrears.
- **Daily Cashbook Tab:**
  - A date picker to select a specific day (defaults to today).
  - Columns: Transaction ID, Church, Amount, Type, Method.
  - A summary footer showing the total collected for that day.
- **Role Isolation:** National sees all; Regional Chairmen see only their region's data.

## Implementation
### 1. Server Actions (`lib/actions/report-actions.ts`)
- `getArrearsReport()`: Fetch all churches with `annualOutstanding > 0` or `monthlyOutstanding > 0`.
- `getDailyCashbook(date: Date)`: Fetch all payments where `payment_date` falls on the selected date.

### 2. UI Components
- `app/dashboard/reports/page.tsx` (Suspense + connection wrapper).
- `components/reports/reports-client.tsx` (Manages the tab state).
- `components/reports/arrears-table.tsx`.
- `components/reports/cashbook-table.tsx`.
