# Unit 12.1: User Profile & Settings

## Goal
Build a functional Settings page where authenticated users can view their role, email, and associated region/church. Include a form to update their password securely via Supabase Auth.

## Design
- **Layout:** Uses the existing `AppShell`. The page will have two main sections:
  1. **Identity Card:** Read-only display of the user's Email, Role (badge), and Region (if applicable).
  2. **Security Card:** A form to update the password (New Password, Confirm Password).
- **UI:** Follow standard shadcn card layouts with semantic tokens.

## Implementation
### 1. Server Action (`lib/actions/user-actions.ts`)
- `getCurrentUserProfile()`: Fetch the user from Supabase Auth and join with the Prisma `User` table to get their role, region, and church details.

### 2. Page & Components
- Update `app/dashboard/settings/page.tsx` (Suspense + connection wrapper).
- Create `components/settings/profile-card.tsx` (Displays user info).
- Create `components/settings/password-form.tsx` (Client component using Supabase client to call `supabase.auth.updateUser({ password })`).

## Verification Checklist
- [x] Settings page loads and displays the correct logged-in user data.
- [x] Role badge matches the user's actual role.
- [x] Password update form successfully changes the password (shows Sonner toast).
- [x] No TypeScript errors.
