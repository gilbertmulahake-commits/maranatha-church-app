# Unit 12.2: User Management (Admin)

## Goal
Build a User Management page restricted to National HQ roles. It will display a table of all system users (Email, Role, Region, Church) and include an "Invite User" dialog that creates a new Supabase Auth account and inserts the corresponding Prisma `User` record.

## Design
- **Layout:** Uses the existing `AppShell`. 
- **Table:** Columns: Email, Role, Region, Church, Date Joined. 
- **Invite Button:** Placed in the `TableToolbar`. Opens a `<Dialog>`.
- **Invite Form:** Email, Password (temporary), Role (Dropdown), Region (Dropdown, required for Regional roles), Church (Dropdown, required for Church roles).

## Implementation
### 1. Server Actions (`lib/actions/user-actions.ts`)
- `getSystemUsers()`: Verify the caller is National HQ. Fetch all `User` records from Prisma, including `region` and `church`.
- `inviteUser(data)`: Verify caller is National HQ. Use `supabase.auth.admin.createUser()` to create the auth account, then `prisma.user.create()` to link the role.

### 2. UI Components
- `app/dashboard/users/page.tsx` (Add to Sidebar).
- `components/users/users-table.tsx`.
- `components/users/invite-user-dialog.tsx`.
