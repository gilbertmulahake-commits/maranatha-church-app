# Unit 14.6: Enterprise UI Polish & Consistency

## Goal
Elevate the UI to a premium enterprise standard. Fix KPI logic bugs (gross arrears, >100% percentages), standardize the drill-down pages (Church Profile, Region Drill-down), and resolve layout inconsistencies.

## Implementation

### 1. Fix Financial Logic (Gross Arrears)
- **Issue:** The National Dashboard currently displays "Net Credit" (e.g., 67,000) if the whole network is overpaid. This hides the fact that individual churches still owe money (e.g., 8,000).
- **Fix:** Update `dashboard-actions.ts`, `regional-actions.ts`, and `region-actions.ts` to calculate `totalArrears` as the sum of only *positive* outstanding balances (`Math.max(0, expected - paid)` per church). 
- **UI:** KPI cards must display "Total Arrears" (red) alongside any Net Credit.

### 2. Fix KPI Cards UI (>100% Bug & Layout)
- **Issue:** If a church or region is heavily prepaid, the KPI card shows broken percentages like `1,142.9%`. 
- **Fix:** Cap the visual progress bar at 100%. If the actual percentage is > 100%, display a green "Target Exceeded" badge instead of the raw broken percentage.
- **Typography:** Enforce strict `text-heading-4` and `tabular-nums` across all KPI cards.

### 3. Mock KCB Layout & UX
- **Issue:** The Mock KCB form is pinned to the left, leaving a massive empty void on the right.
- **Fix:** Convert the `components/mock-kcb-form.tsx` wrapper to a 2-column grid on desktop.
- **Right Column:** Add a "Testing Guide" card that outlines the priority rules (Annual Arrears → Current Annual → Monthly Arrears → Future Years) and explains how to use the "Auto" payment type.

### 4. Harmonize Drill-Downs
- **Church Profile (`/dashboard/churches/[code]`):**
  - Replace the bare "Total Collected" card with the exact `LocalKpiCards` component used on the Local Dashboard.
  - Replace the "Recent Payments placeholder" with the `LocalPaymentHistory` table.
- **Region Detail (`/dashboard/regions/[slug]`):**
  - Ensure the KPI cards and tables match the Chairman's Regional Dashboard (`regional-dashboard-client.tsx`) exactly.
