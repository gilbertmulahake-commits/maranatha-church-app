# Unit 11.2: CSV Export Engine

## Goal
Add CSV export functionality to the Payments Ledger, the Arrears Report, and the Daily Cashbook. Users must be able to download the exact data currently filtered in their view.

## Design
- **UI:** Add a "Download CSV" button (with a `Download` icon) to the `TableToolbar` or the header of the tables.
- **Format:** Standard CSV (comma-separated values) with headers.
- **Behavior:** 
  - Clicking the button downloads a `.csv` file immediately.
  - The file name should include the report type and date (e.g., `arrears-report-2026-11-06.csv`).
  - **Crucial:** It must export the *filtered* data, not just the paginated page. If the user searches for "CH001", only CH001 is exported.

## Implementation
### 1. Utility Function (`lib/utils/export.ts`)
- Create a generic `exportToCsv(filename: string, rows: object[])` function.
- It should extract keys from the first object as headers, format the rows, escape commas, and trigger a browser download using a Blob.

### 2. Table Integrations
- Update `components/payments/payments-table.tsx`: Add an export button that exports the `sortedData` (filtered data).
- Update `components/reports/arrears-table.tsx`: Add an export button that exports the `sortedData`.
- Update `components/reports/cashbook-table.tsx`: Add an export button that exports the `data`.
