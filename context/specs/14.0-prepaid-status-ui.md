# Unit 14.0: Prepaid Status UI (Phase 1)

## Goal
Surface "X Years Prepaid" status in the church tables based on existing cumulative credit math. 
This provides immediate clarity to Treasurers and Pastors without risking production bank reconciliation.

## Design Decisions
- **NO Backend Changes:** The KCB webhook and Payment records remain untouched. 1 payment = 1 bank transaction.
- **NO Schema Changes:** Deferring the `PaymentAllocation` table to V2.
- **UI Translation:** Translate the existing `annualCredit` and `monthlyCredit` into human-readable "Prepaid" units.

## Implementation

### 1. Helper Function (`lib/utils/format.ts`)
Add a new helper to calculate and format the prepaid status.

```typescript
export function formatPrepaidStatus(credit: number, type: 'Annual' | 'Monthly'): string | null {
  if (credit <= 0) return null

  if (type === 'Annual') {
    const years = Math.floor(credit / 5000)
    if (years >= 1) return `Paid (${years} Year${years > 1 ? 's' : ''} Prepaid)`
    return `Credit: ${new Intl.NumberFormat('en-KE', { style: 'currency', currency: 'KES', maximumFractionDigits: 0 }).format(credit)}`
  } else {
    const months = Math.floor(credit / 500)
    if (months >= 1) return `Paid (${months} Month${months > 1 ? 's' : ''} Prepaid)`
    return `Credit: ${new Intl.NumberFormat('en-KE', { style: 'currency', currency: 'KES', maximumFractionDigits: 0 }).format(credit)}`
  }
}
```

### 2. UI Updates
- Update `components/churches/church-table.tsx`: Replace the current `Credit: KES X` display with `formatPrepaidStatus(annualCredit, 'Annual')` or `formatPrepaidStatus(monthlyCredit, 'Monthly')` based on the active `periodView`.
- Update `components/regional/regional-table.tsx`: Apply the same logic to the Regional table.
